# 764 CL4N Loader: нативное приложение (C# / WPF, .NET 8)

Окно рисуется самой Windows (WPF), без браузера внутри: свой заголовок с крестиком, шапка с логотипом и ником, меню, описание, статус связи и кнопка «Запустить». Сайт по кнопке открывается окном Edge/Chrome без адресной строки.

## Сборка без установки чего-либо
1. Залей сайт в репозиторий GitHub (вместе с папками `native/` и `.github/`).
2. Выпусти релиз: «Releases → Create a new release», тег `v1.0.0`, «Publish release». Запустится сборка (вкладка Actions, 3–6 минут).
3. В релизе появится `764CL4N-Loader.exe`. Впиши `var REPO='логин/репозиторий';` в `dl.js`, и кнопка «Скачать» на сайте начнёт отдавать этот файл.

## Сборка у себя
Установи .NET 8 SDK и выполни в папке `native`:
`dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o out`

## Заметки
- Файл самодостаточный (внутри .NET), поэтому весит несколько десятков МБ и ничего доустанавливать не нужно.
- Без цифровой подписи Windows покажет «Неизвестный издатель»: «Подробнее» → «Выполнить в любом случае».
- Адрес сайта задан в `MainWindow.xaml.cs` (`BASE`); при переезде на свой домен поменяй там.

## Тест без выкладки на сайт
1. Дважды кликни `test-site.bat` (нужен Python) и открой http://localhost:8080.
2. Дважды кликни `test-loader.bat` (нужен .NET 8 SDK): лоудер откроется и будет ходить на localhost.
3. Положи свой `764CL4N-Loader.exe` в папку сайта, и кнопка «Скачать» на localhost отдаст его.
